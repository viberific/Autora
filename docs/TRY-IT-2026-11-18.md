# Autora, tried end to end (2026-11-18, 0.9.372 -> 0.9.373)

Three agents and one hands-on pass, each on its own app instance (`tests/e2e-harness.ts`, scripted stand-in model, headless
Chromium). **Limits:** the model was scripted, so this tests how the app reacts, not what a real model would choose or cost.
Built here: the root UI and GDevelop (Games). **Not built:** Pages/Sheets/Slides, PDF, Video, 3D, Photo (needs `trunk`), so
those were checked only on the "not installed" path. Real touch, audio, Safari/Firefox and a light theme (there is none) were
not tried.

## Open, ranked

**P2**
- Games have no live Visible-work hand; no `game_export`; no art, placeholder-sprite or sound tools in the game family (a
  Sprite with no image is invisible); `game_play` returns pictures only (no scene variables or object positions).
- Creator (`app_preview`): no way to read page state (a held key now works).
- Panacea N2-N8 (code, run, db and app surfaces, shipping to Umbrel) are all open; the native Table cannot edit cells,
  and documents have no tables, headers or DOCX. 34 of 145 recipes are hidden because nothing acts on them (honest).
- On a phone, the Games and Creator windows show as ~110 px thumbnails in a corner of the canvas.
- Keyboard: the composer is the 29th Tab stop (`/` focuses it, but nothing says so); the rail could be one roving stop.
- Conversation docked right, or minimised, overlaps the work or its own icons; iPad portrait gets the desktop float rather
  than the phone sheet; a duplicate icon rail appears when Music opens.

**P3**
- `panacea_set` still accepts a key far from any control (`nonexistent.value`): the canvas keeps free values, so only near misses are refused.
- `studio_export` with no open tab says "did not start" instead of "needs the window open".
- `toolbudget`: the briefing is within 14 characters of its 29,000 budget with Games built (27,820 without).
- Panel chips are 15-24 px high.
- Redaction still cannot catch a key that is split, spaced or otherwise transformed on purpose.
- Console noise from GDevelop's calls to `api.gdevelop.io`. Platformer template and `game_template` Sprite are incomplete.
- Sidebar names: "Threads" (agents' forum) beside "Sessions" and "Chat" is easy to confuse.

## Checked and fine
All 14 sidebar pages open with no console errors, failed requests or horizontal scroll at 1280-2560, iPad and iPhone.
Cross-site POSTs, cross-site websockets and a foreign `Host` are refused; artifact HTML/SVG is served sandboxed; the
secret in `echo $KEY` is blanked. Esc closes the chooser; Enter/Shift+Enter work; reduced motion is honoured; keyboard
move, resize, snap and minimise of the chat window work. A scripted agent built a playable platformer (move, collect, win,
fall, restart; Panacea's Game panels changed the real behaviour) and a canvas game in about a minute of tool time.
